## درباره این مخزن

این مخزن مجموعه‌ای از **یادداشت‌های فارسی و غیررسمی** دوره [مهندسی داده و مهندسی هوش مصنوعی](https://mostafaghadimi.github.io/data-course/) به میزبانی **مصطفی قدیمی** است. جزوه‌ها بر اساس توضیحات جلسات تدوین می‌شوند و هدفشان این است که مطالب کلاس برای مطالعه، تمرین و مرور در آینده، منظم و قابل‌فهم باقی بمانند.

در تهیه هر جزوه تلاش می‌شود:

- مفهوم صحبت‌های مدرس، مثال‌ها و نکات کاربردی حفظ شود.
- تکرارهای گفتاری و خطاهای متن پیاده‌سازی‌شده اصلاح شوند، بدون تغییر در منظور مدرس.
- توضیحات جدید با عنوان **«تکمیل فنی»** و نمونه‌های افزوده‌شده با عنوان **«مثال اضافی»** از محتوای کلاس جدا باشند.
- ادعاهای فنیِ نیازمند بررسی، تا حد امکان با مستندات معتبر سنجیده شوند.
- اصطلاحات شناخته‌شده انگلیسی حفظ و مفاهیم با زبان ساده توضیح داده شوند.

> **یادداشت مهم:** این یک پروژه مستقل دانشجویی است، نه مخزن رسمی دوره. توضیحات تکمیلی این مخزن الزاماً نظر مدرس یا برگزارکنندگان نیست.

## مسیرهای آموزشی

دوره دو مسیر **Data Engineering** و **AI Engineering** دارد که برخی مباحث مقدماتی آن‌ها مشترک است.

### مهندسی داده (Data Engineering)

آشنایی با مسیر حرکت داده از منابع مختلف تا فراهم‌شدن داده قابل استفاده برای تحلیل و محصولات نرم‌افزاری؛ از جمله مفاهیم زیر که در جلسه معرفی دوره مطرح شده‌اند:

- Data Sources، Data Ingestion و Data Pipelines
- Database، SQL و مبانی سیستم‌های توزیع‌شده
- Data Warehouse، Data Lake و Data Lakehouse
- ETL / ELT، Batch / Stream Processing
- Data Modeling، Orchestration و Data Quality
- Observability و مفاهیم زیرساختی مرتبط

### مهندسی هوش مصنوعی (AI Engineering)

آشنایی با ساخت محصولات مبتنی بر مدل‌های موجود و موضوعاتی مانند AI Agents، ابزارها، Guardrails، ارزیابی خروجی، هزینه و مانیتورینگ. **برنامه تفصیلی این مسیر در جلسه اول هنوز نهایی نشده بود** و به‌تدریج مطابق جلسات برگزارشده تکمیل می‌شود.

## روش استفاده از جزوه‌ها

۱. از [جلسه اول](sessions/01-introduction.md) شروع کنید و مباحث را به ترتیب بخوانید.

۲. برای هر مفهوم، توضیحات کلاس و مثال‌های مدرس را مرور کنید.

۳. بخش **«تکمیل فنی»** را از متن اصلی جلسه تفکیک کنید؛ این بخش برای رفع ابهام، بررسی محدودیت‌ها و دقت بیشتر نوشته شده است.

۴. تمرین‌ها یا مثال‌های عملی را خودتان اجرا کنید و سپس سوال‌های مرور را پاسخ دهید.

۵. برای جزئیات بیشتر، به ویدیوها، اسلایدهای دوره و مستندات معرفی‌شده مراجعه کنید.

## مشارکت و گزارش خطا

اگر اشتباه فنی، توضیح نامفهوم، مشکل نمایش فارسی یا لینک خراب مشاهده کردید، یک **Issue** ثبت کنید. برای اصلاح مطالب نیز می‌توانید **Pull Request** بفرستید. شیوه نام‌گذاری فایل‌ها و اصول نگارش در [CONTRIBUTING.md](CONTRIBUTING.md) آمده است.

در هر پیشنهاد اصلاحی، لطفاً مشخص کنید که تغییر مربوط به **متن کلاس** است یا **تکمیل فنی**؛ این تفکیک برای امانت‌داری آموزشی ضروری است.
